清拆服務常見問題

清拆工程一般需要多長時間完成？

✅ 詳細工期分析

  • 標準住宅（300-500平方呎）：
    ✓ 基本清拆：1-2個工作日
    ✓ 含廢料清運：需額外0.5天
  • 商業空間（500-1000平方呎）：
    ✓ 辦公室：2-3天（需處理系統傢俬）
    ✓ 餐廳：3-4天（含油煙系統拆除）

✅ 影響工期關鍵因素

  • 建築結構（混凝土牆比石膏板多50%工時）
  • 廢料處理（高層無貨梯需加30%時間）
  • 施工限制（部分商廈只准非辦公時間作業）

✅ 業主須知

  • 建議預留10-15%緩衝時間應對突發狀況
  • 可要求每日進度報告（含現場照片）

如何準確估算清拆工程費用？

✅ 報價組成要素

✅ 隱藏成本警示

  • 石棉檢測：$1500-3000（1985年前建築強制要求）
  • 夜間施工：加收20-30%（需申請噪音許可）

✅ 省錢建議

  • 自行拆除可回收物品（如金屬門窗）可減$3-5/呎
  • 非旺季（1-3月）通常有5-10%折扣

清拆工程是否需要購買保險？

✅ 必備保險類型

  • 第三者責任險（最低$500萬保額）：保障鄰居或公共設施損壞
  • 工人意外險：法定要求，保障施工人員安全
  • 工程全險（可選）：涵蓋火災、水浸等意外

✅ 業主注意事項

  • 要求承建商出示有效保單副本
  • 確認保單涵蓋整個施工期

舊傢俬電器有哪些處理方式？

✅ 環保回收選項

  1. 可回收物品（金屬、塑膠、玻璃等）： 交由政府認可回收商處理部分慈善機構接受捐贈（如傢俬、家電）
  2. 電子廢物（電腦、電視、冷氣等）： 按環保署規定，由持牌回收商處理可查詢社區回收點或「綠在區區」計劃

✅ 無法回收的廢棄物

  • 運往政府指定廢料收集站
  • 確保符合環保法規，避免非法棄置

✅ 注意事項

  • 捐贈前請確認物品狀況（是否仍可使用）
  • 大型傢俬需自行安排運輸或聯絡回收商上門收取

清拆完工驗收要注意哪些細節？

✅ 驗收標準檢查表

✅ 文件核對

  • 必須取得：
    ✓ 清拆完工證明（列明工程範圍）
    ✓ 廢料處置記錄（載明重量/處理方式）
    ✓ 石棉檢測報告（如適用）

  • 雙方簽署「驗收確認書」

清拆期間是否需要搬出？

✅ 一般建議

  1. 短期工程（1-2天）： 可留在屋內，但建議關閉施工區門窗敏感人士（如幼兒、長者）可考慮暫時避開施工時段
  2. 大型工程（3天以上）： 若施工範圍廣或粉塵較多，建議暫時搬離可自行安排住宿或使用防塵措施（如密封房間）

✅ 注意事項

  • 清拆期間可能會有噪音及粉塵，請提前做好準備
  • 貴重物品建議自行保管或遠離施工區域

如有疑問，請提前與施工團隊溝通安排。

售後服務具體包含哪些保障？

✅ 基本保障範圍

  1. 工程質量保證（通常6個月內有效）： 若因清拆工程導致結構問題（如牆身裂縫、漏水），可安排免費檢修不包含後續裝修或其他工程造成的損壞
  2. 廢料處理確認： 確保所有廢料合法處理，避免業主承擔環保責任

✅ 糾紛處理方式

  • 若對工程有疑問，可要求第三方專業驗樓師覆檢
  • 按合約條款釐清責任歸屬，確保公平解決

注意事項

  • 售後服務需保留完工證明文件
  • 非工程相關問題（如大廈原有結構缺陷）不在保障範圍內

如有疑問，可聯絡施工團隊查詢詳細條款。
